## 📝 Описание

**VioletChat** — это современный мессенджер с фиолетовой темой, разработанный в рамках дипломной работы. Приложение позволяет пользователям обмениваться сообщениями в реальном времени, создавать личные чаты и общаться в общем чате.

### ✨ Основные возможности

- 🔐 **Аутентификация** — регистрация и вход с JWT-токенами
- 💬 **Общий чат** — общение всех пользователей в реальном времени
- ✉️ **Личные чаты** — приватные сообщения между пользователями
- 👥 **Статус онлайн** — отображение активных пользователей
- 🎨 **Фиолетовая тема** — стильный и современный дизайн
- 📱 **Адаптивный интерфейс** — работает на всех устройствах

## 🛠️ Технологии

### Backend
- **Java 17** — основной язык
- **Spring Boot 3.1.5** — фреймворк
- **Spring Security** — аутентификация и авторизация
- **Spring Data JPA** — работа с БД
- **Spring WebSocket** — обмен в реальном времени
- **PostgreSQL** — база данных
- **Liquibase** — миграции
- **JWT** — аутентификация
- **MapStruct** — маппинг Entity ↔ DTO
- **Lombok** — уменьшение кода
- **OpenAPI 3.0** — документация API

### Frontend
- **HTML5** — структура
- **CSS3** — стилизация (фиолетовая тема)
- **JavaScript (ES6)** — логика
- **WebSocket API** — реальное время

### Тестирование
- **JUnit 5** — тестирование
- **Mockito** — мокирование
- **Testcontainers** — тесты с БД
